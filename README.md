# Product_landing_Page
🎧 Product Landing Page – Bassheads 900 Pro
A sleek, responsive product landing page for showcasing the Bassheads 900 Pro Wired Headphones, with smooth animations, customer reviews, specifications, and a sticky navigation bar for seamless user experience.

🚀 Features
Clean and modern UI
Scroll-triggered image zoom animation
Reviews section with entry animations
Product specifications in grid layout
Fully responsive layout (mobile/tablet/desktop)
Sticky navigation bar
Footer with social/contact placeholders

🧰 Technologies Used
HTML5
CSS3 (Flexbox, Media Queries)
JavaScript (scroll-triggered animations)
